ProWizard: multi-tenant HCM and staffing SaaS platform

ProWizard gives staffing teams visibility across the whole employee lifecycle: recruiting, scheduling, pipeline, gross payroll, invoicing, expenses, timesheets, CRM, and travel. It supports this with real-time analytics and reporting, subdomain-based tenant resolution, and a separate database for each tenant.

Design and delivery

  • Architected and built the platform on ASP.NET Core 8 MVC (Razor SSR) with a Clean/Layered Architecture Web API backend and Dapper.
  • Led a team of 12 engineers while working onsite with the client for two years, at OpsArc's Phoenix, Arizona office.
  • Designed the hybrid multi-tenant data model: a shared common Azure SQL database plus isolated per-tenant databases in Elastic Pools, with subdomain-based tenant resolution.
  • Diagnosed and resolved critical production performance incidents, including a tenant database running at 100% DTU, through Query Store analysis, execution-plan interpretation, index redesign, and stored-procedure rewrites.
  • Re-engineered high-traffic stored procedures with a two-phase paging pattern, using lightweight CTE keyset paging followed by decoration joins. This removed optimizer timeouts and cross-tenant row fan-out bugs.
  • Implemented Azure AD/Entra ID single sign-on and RBAC, JWT and refresh-token authentication, and secrets management in Azure Key Vault.
  • Delivered the Travel Management module end to end: a six-step MVC request wizard with controller and partial-view architecture and AJAX-driven step navigation.
  • Led CRM module UX and data-consistency work, and supported ACA compliance reporting and data-quality remediation.
  • Built and maintain a 24-module platform documentation site with a custom Python static-site generator, and own CI/CD pipelines and Application Insights observability.

ProWizard Migration Pipeline: legacy database migration

A pipeline for onboarding new ProWizard tenants by migrating their legacy customer databases. It covers schema mapping, data mapping, rollback, and validation, and it can resume after an interruption.

Design and delivery

  • Architected a .NET console-based migration pipeline that moves legacy customer databases into ProWizard's multi-tenant schema.
  • Built automated schema-mapping and data-mapping generation, producing mapping files and stored procedures for each source schema.
  • Applied parallel processing with the Task Parallel Library to cut migration time on large datasets.
  • Designed a dedicated rollback pipeline and a validation pipeline to confirm data integrity after each migration.
  • Added execution-history tracking so an interrupted migration resumes from the last completed step instead of starting over.
